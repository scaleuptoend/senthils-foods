# Senthil Food Center — PWA

This folder is a Progressive Web App package.

## Deploy
Upload the entire folder contents to an HTTPS web host. The main file is `index.html`.

## Install on phone
Open the HTTPS address in Chrome/Safari and use the browser's **Install app / Add to Home Screen** option.

## Important
The app can open from its cached shell when offline. Cloud sync still requires an internet connection; local data remains available on the device while offline.
